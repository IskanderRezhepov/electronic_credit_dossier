
# Электронное кредитное досье — версия 0.2

Эта версия протестирована на двух реальных PDF:

- договор финансового лизинга;
- договор купли-продажи.

## Установка

```powershell
python -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python run.py
```

Откройте:

```text
http://127.0.0.1:5000
```

## Важно

Загрузите оба PDF одновременно, выделив их в окне выбора файлов.

# Электронное кредитное досье — версия 0.5

Программа читает цифровые PDF, сканы PDF, изображения, DOCX и TXT. Она классифицирует документы и извлекает ключевые поля.

## Поддерживаемые семейства документов

- договор купли-продажи;
- договор финансового лизинга / заявление о присоединении;
- акт приёма-передачи;
- график погашения;
- дополнительное соглашение;
- договор гарантии / поручительства;
- счёт / счёт-фактура;
- квитанция о подписании;
- неизвестный документ с универсальным извлечением ИИН/БИН, VIN, IBAN, DOC ID и денежных сумм.

## Важный принцип

«Прочитать любой файл» и «точно понять любой новый шаблон» — разные задачи. OCR читает текст почти любого скана, но смысловые поля нового шаблона требуют либо специального парсера, либо ручной проверки. Поэтому программа показывает источник, страницу, уверенность и статус каждого значения.

## Запуск

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run.py
```

Открыть: http://127.0.0.1:5000


## Изменения v0.6

- исправлено извлечение итоговой суммы акта, когда перед суммой стоит количество;
- добавлены резервные правила для номера договора в графике;
- улучшено извлечение ролей сторон;

- обновлён .gitignore для instance, venv и OCR-артефактов.


## Изменения v0.7

- классификация учитывает имя файла и заголовок первой страницы;
- ДКП больше не должен классифицироваться как акт из-за упоминания акта внутри договора;
- номера вроде `1-КОСЫМША` отклоняются как OCR-ошибка;
- график выбирает наиболее правдоподобный номер договора;
- компактные номера вроде `KAZ14112024KTL` поддерживаются;
- 17-значные идентификаторы группируются по префиксам, чтобы не складывать VIN и номера шасси;
- расчёт количества имущества использует крупнейшую однородную группу, а не общее число кодов;
- предупреждения показывают русские названия полей;
- добавлены автоматические тесты;
- `.gitignore` исключает `.venv`, `instance` и реальные документы.

Запуск тестов:

```powershell
pytest -q
```

Важно: расчёт количества по группам идентификаторов является кандидатом и должен
сверяться с таблицей акта. Следующий этап — полноценное извлечение строк таблиц.

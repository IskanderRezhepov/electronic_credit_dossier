# Flask-анализатор электронного кредитного досье — версия 0.1

## Установка

1. Установите Python 3.12.
2. Откройте папку проекта в VS Code.
3. Откройте Terminal → New Terminal.
4. Выполните:

```powershell
python -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python run.py
```

5. Откройте:

```text
http://127.0.0.1:5000
```

## Первый тест

- `F-189620678_ДЛ_ИП КОРГАНОВ.pdf`
- `F-1638892498_ДКП_ИП КОРГАНОВ поставщик+клиент.pdf`

## Что проверяется

- тип документа;
- номера связанных договоров;
- стоимость;
- описание имущества;
- ИИН/БИН;
- количество ЭЦП;
- аванс и сумма финансирования;
- соответствие комиссии 1%.

## Важно

Это пилотная версия для двух первых шаблонов. Она не заменяет юридическую проверку.

# Электронное кредитное досье v0.4

Версия 0.4 исправляет ошибки, найденные на OCR-результатах:

- случайные слова больше не принимаются за номер документа;
- первая найденная дата больше не подставляется как дата договора;
- общая сумма акта не должна превращаться в количество (`607`);
- номера договоров допускают точки, дефисы и слэши и нормализуются;
- универсальные суммы и ИИН/БИН помечаются как **кандидаты**, а не подтверждённые поля;
- для двуязычных страниц OCR отдельно читает правую русскую колонку и всю страницу;
- качество OCR рассчитывается из confidence Tesseract, а не задаётся фиксированным `0.82`;
- добавлен раздел «Требует проверки»;
- Excel содержит статус, примечания и отдельные листы контроля.

## Установка

```powershell
python -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python run.py
```

Для фотографий и сканов требуется Tesseract OCR с языками `rus`, `kaz`, `eng`.

## Поддерживаемые форматы

PDF, PNG, JPG/JPEG, TIFF/TIF, BMP, WEBP.

## Важный принцип

Программа различает:

- **извлечённое поле** — найдено по шаблону и прошло базовую проверку;
- **кандидат** — найден универсальным поиском, но роль значения ещё не подтверждена;
- **предупреждение** — значение отсутствует, подозрительно или имеет низкую уверенность OCR.

Новый неизвестный шаблон всё равно требует добавления специализированного парсера и тестовых документов.

# Электронное кредитное досье — версия 0.5

Программа читает цифровые PDF, сканы PDF, изображения, DOCX и TXT. Она классифицирует документы и извлекает ключевые поля.

## Поддерживаемые семейства документов

- договор купли-продажи;
- договор финансового лизинга / заявление о присоединении;
- акт приёма-передачи;
- график погашения;
- дополнительное соглашение;
- договор гарантии / поручительства;
- счёт / счёт-фактура;
- квитанция о подписании;
- неизвестный документ с универсальным извлечением ИИН/БИН, VIN, IBAN, DOC ID и денежных сумм.

## Важный принцип

«Прочитать любой файл» и «точно понять любой новый шаблон» — разные задачи. OCR читает текст почти любого скана, но смысловые поля нового шаблона требуют либо специального парсера, либо ручной проверки. Поэтому программа показывает источник, страницу, уверенность и статус каждого значения.

## Запуск

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run.py
```

Открыть: http://127.0.0.1:5000

## Изменения v0.7

- классификация учитывает имя файла и заголовок первой страницы;
- ДКП больше не должен классифицироваться как акт из-за упоминания акта внутри договора;
- номера вроде `1-КОСЫМША` отклоняются как OCR-ошибка;
- график выбирает наиболее правдоподобный номер договора;
- компактные номера вроде `KAZ14112024KTL` поддерживаются;
- 17-значные идентификаторы группируются по префиксам, чтобы не складывать VIN и номера шасси;
- расчёт количества имущества использует крупнейшую однородную группу, а не общее число кодов;
- предупреждения показывают русские названия полей;
- добавлены автоматические тесты;
- `.gitignore` исключает `.venv`, `instance` и реальные документы.

Запуск тестов:

```powershell
pytest -q
```

Важно: расчёт количества по группам идентификаторов является кандидатом и должен
сверяться с таблицей акта. Следующий этап — полноценное извлечение строк таблиц.


## Изменения v0.8

- поля со значением `None` больше не отображаются как успешно извлечённые;
- денежные шаблоны требуют фактическую цифру, а не пробелы после заголовка;
- имя графика `F-210018188_AG2-2022-U-L-113039 ...` преобразуется в кандидата
  `AG2/2022/U/L/113039`, без технического F-номера и даты;
- PDF с несколькими актами получает поле `Номера актов в пакете`, а не ложную
  ошибку об одном отсутствующем номере;
- `.gitignore` включён в проект;
- удалены сохранённые runtime-результаты и `__pycache__`;
- добавлены регрессионные тесты для денежных сумм.

После распаковки:

```powershell
python -m pip install -r requirements.txt
pytest -q
python run.py
```

Если `instance` уже отслеживался старым Git-репозиторием:

```powershell
git rm -r --cached instance .venv
git add .gitignore instance/.gitkeep
git commit -m "Ignore runtime files and virtual environment"
```

## Изменения v1.0

- ИИН/БИН и IBAN теперь автоматически привязываются к ролям сторон по контексту:
  продавец, покупатель, лизингополучатель и лизингодатель.
- Неоднозначные значения не назначаются случайно и остаются в блоке
  «Неопределённые ИИН/БИН».
- Уже подтверждённые суммы исключаются из шумного списка денежных кандидатов.
- OCR переведён на адаптивный режим: дополнительные проходы запускаются только
  для слабых страниц.
- Добавлен постоянный OCR-кэш в `instance/ocr_cache`. Повторный анализ того же
  скана выполняется значительно быстрее.
- DPI по умолчанию снижен до 190 для более быстрой обработки длинных сканов.
- Улучшено чтение номера основного договора в OCR-дополнительных соглашениях.

После обновления рекомендуется один раз удалить старые результаты:

```powershell
Remove-Item -Recurse -Force instance\results -ErrorAction SilentlyContinue
```
